# Documentation map

## Research deliverables

- `../draft/`: current manuscript draft.
- `../reports/`: canonical results, audits, and reproducibility reports.
- `../submission_neutral/`: public-submission and artifact checklist.

## Project records

- `project_management/`: plans, agent tasks, and milestone notes.
- `feedback/`: external review and feedback that informed revisions.
- `research_notes/`: technical background and design notes.
- `archive/generated/`: generated HTML, plots, and legacy presentation outputs.
- `submission_figures/`: figures used by the current manuscript/review brief.

The canonical scientific results remain under `reports/`; archived material is
kept for provenance but is not part of the primary 138-pair evidence set.
