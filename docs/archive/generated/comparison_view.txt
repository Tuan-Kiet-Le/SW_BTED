The client has provided the following detailed workflow:
1.	Full workflow (Overall Operational Process)
The overall operation lifecycle of the platform involves sequential stages among the participating actors:
a.	Initialization Phase (User): The User accesses the mobile application to Submit a Request, providing details and images of the electronic waste.
b.	Dispatch Phase (System): The System receives the request, processes the data, and automatically executes Route Planning to assign the task to an appropriate Collector.
c.	Collection Phase (Collector): The Collector accepts the task, travels to the user's location to perform the Pickup, and transports the collected items to the warehouse.
d.	Warehousing Phase (Warehouse Staff): The Warehouse Staff receives items from the Collector, performs inspection, and executes Check-in/Storage.
e.	Recycling Phase (Recycler): The Warehouse initiates the Transfer of batched waste to the Recycler for final processing.
2.	Pickup Request Submission (User Request Creation Process)
Detailed steps for a user to create a new collection request:
a.	Start: The User logs into the application and selects the "Create Collection Request" function.
b.	Photo Authentication: The User captures a photo of the device intended for disposal.
c.	AI Verification: The AI system analyzes the captured image:
d.	Invalid Case: The system displays an error (e.g., "non-e-waste detected" or "Unclear image"). The User is required to retake the photo.
e.	Valid Case: The system approves the image and proceeds to the next step.
f.	Input Details: The User provides specific details: Pickup Address, Device Category, and Preferred Time Slot.
g.	Completion: The User clicks "Submit." The system saves the request with a "Pending" status and notifies the user of success.
3.	Collection & Routing (System Dispatch & Collector Process)
The process for route optimization and on-site collection:
a.	Route Optimization (System): The system aggregates Pending Requests and executes a routing algorithm to batch orders and generate the optimal path for the Collector.
b.	Task Assignment: The system sends the route and pick-up list to the Collector via the mobile app.
c.	Travel & Verification (Collector):
d.	The Collector navigates the user’s address using the map integration.
e.	On-site, the Collector verifies the physical device against the request details.
f.	Collection Decision:
g.	Match: The Collector confirms the application, collects the item, and loads it onto the vehicle. The status updates to "Collected."
h.	Mismatch: The Collector rejects the collection or updates the correct information on the system before acceptance.
i.	End Route: Upon completing the route, the Collector transports all collected items to the central warehouse.
4.	Inventory & Recycling Transfer (Warehouse Entry & Transfer to Recycler Process)
The workflow for managing inventory from check-in to export:
a.	Inventory Check-in: Upon the Collector's arrival at the warehouse, the Warehouse Staff scans the code (QR Code/Barcode) on each device to confirm entry.
b.	Categorization & Storage: The system updates the status to "In Stock." Devices are categorized and placed in their respective storage zones.
c.	Batch Creation: When a sufficient quantity is accumulated, the Warehouse Staff groups devices into a Batch for export.
d.	Handover: The Warehouse Staff generates an export slip and physically hands over the batch to the Recycler.
e.	Confirmation: The Recycler confirms receipt. The system updates the final status of the devices to "Transferred to Recycler."
5.	Direct Drop-In (User Drop-off Process)
The process for users who bring waste directly to the collection point:
a.	User Arrival: The User brings the electronic waste directly to the System’s Warehouse or Collection Hub.
b.	Reception (Staff): The Staff inspects the physical condition of the device.
c.	System Logging: The Staff uses Admin Portal to log a new request on behalf of the User.
d.	Completion:
o	The device is immediately checked into the inventory (skipping the transportation phase).
o	The system records the successful transaction and awards Points to the User's account.
The system recognizes the following key actors:
1.	User: Posts device details, schedules collections, and tracks collection status.
2.	Collector: Follows assigned routes, collects items, and attaches QR codes.
3.	Warehouse Admin: Verifies item conditions, confirms user rewards, and prepares packages.
4.	Collection Company Admin: Manages collectors, coordinates vehicles, and oversees collection hubs.
5.	System Admin: Moderates posts and oversees platform operations.
6.	Recycler: Receives packages and processes items for recycling.
7.	System Handler: Coordinates all automated processes.

   a. User Initialization Phase: Users engage with the mobile application to submit a collection request, including relevant details and images of the electronic waste.

   c. Collector Collection Phase: The Collector accepts the assignment, travels to the user's location to carry out the Pickup, and conveys the collected items to the designated warehouse.
   d. Warehouse Processing Phase: Warehouse personnel receive the items from the Collector, conduct an inspection, and manage the Check-in/Storage process.
   e. Recycling Transfer Phase: The warehouse staff initiates the Transfer of collected waste batches to the Recycler for final processing.

2. User Request Creation Process
The detailed steps for a user to initiate a new collection request include:
   a. Initiation: The user logs into the application and selects the "Initiate Collection Request" feature.
   b. Image Capture: The user takes a photograph of the device intended for disposal.
   c. AI Assessment: The AI component evaluates the captured image.
   d. Invalid Outcome: Should the system identify an error (e.g., "not an e-waste item" or "image unclear"), the user must retake the photo.
   e. Valid Outcome: The system validates the image and advances to the subsequent step.
   f. Detail Entry: The user inputs specific information including Pickup Address, Device Type, and Preferred Collection Time.
   g. Finalization: The user clicks "Submit," and the system saves the request status as "Pending," while notifying the user of success.

3. System Dispatch and Collector Procedure
The method for optimizing routes and executing on-site collections is as follows:
   a. Route Optimization: The system consolidates pending requests and applies a routing algorithm to cluster orders and devise the most efficient path for the Collector.
   b. Task Notification: The system relays the optimized route and pickup details to the Collector via the mobile application.
   c. Collector Navigation and Verification: The Collector utilizes integrated mapping to navigate to the user's address.
   d. On-Site Verification: Upon arrival, the Collector confirms the physical device against the details specified in the request.
   e. Collection Decision-Making:
      - Matched Scenario: The Collector verifies the application, collects the item, and loads it into the vehicle, updating the status to "Collected."
      - Mismatched Scenario: The Collector declines the collection or amends the information in the system prior to accepting the item.
   f. Route Completion: After all pickups, the Collector transports the items to the central warehouse.

4. Inventory Management and Recycler Transfer Process
The workflow for handling inventory from check-in through export is as follows:
   a. Inventory Check-in: Upon the Collector's arrival, the Warehouse staff scans the QR Code/Barcode for each device to verify entry.
   b. Categorization and Storage: The system updates the status to "In Stock," categorizing devices and placing them in designated storage areas.
   c. Batch Assembly: Once a sufficient quantity is accrued, Warehouse staff consolidate devices into a Batch for transfer.
   d. Handover Procedure: Warehouse personnel create an export slip and physically transfer the batch to the Recycler.
   e. Receipt Confirmation: The Recycler acknowledges receipt, prompting the system to update the status of the devices to "Transferred to Recycler."

5. User Drop-off Process
This process accommodates users who deliver waste directly to the collection site:
   a. User Check-in: The User presents the electronic waste at the System’s Warehouse or Collection Hub.
   b. Staff Reception: Staff members inspect the physical condition of the device.
   c. System Logging: Staff utilize the Admin Interface to log a new request on behalf of the User.
   d. Completion: 
      - The device is promptly checked into inventory (bypassing the transportation phase).
      - The system records the transaction's success and awards Points to the User's account.

The system identifies several key participants:
1. User: Submits device information, schedules pickups, and monitors collection status.
2. Collector: Adheres to designated routes, retrieves items, and affixes QR codes.
3. Warehouse Personnel: Assesses item conditions, validates user rewards, and organizes packages.
4. Collection Company Administrator: Supervises collectors, coordinates vehicles, and manages collection hubs.
5. System Administrator: Oversees posts and monitors platform functionality.
6. Recycler: Accepts packages and processes items for recycling.
7. System Coordinator: Orchestrates all automated operations.
