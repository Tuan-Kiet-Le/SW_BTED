# SW-BTED Reproducibility Package

This package documents how to reproduce the frozen four-layer scientific
version. It assumes the repository root is the current working directory and
that dependencies are installed from `requirements.txt`.

## Environment

- Python 3.13.5 was used for the current local run.
- The primary local test command is:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -q
```

- The local MiniLM snapshot is used for offline runs. Qwen3 raw scores are
  supplied as an external artifact from the Kaggle execution and are not
  regenerated by the local CPU pipeline.

## Reproduction commands

Run from the repository root:

```powershell
.venv\Scripts\python.exe experiments\final_canonical_results_138.py
.venv\Scripts\python.exe experiments\clean_baseline_suite_138.py
.venv\Scripts\python.exe experiments\qwen3_threshold_protocol_audit_005.py
.venv\Scripts\python.exe experiments\clean_structural_perturbation_20.py
.venv\Scripts\python.exe experiments\runtime_benchmark_canonical_138.py
.venv\Scripts\python.exe experiments\canonical_interpretability_trace_3.py
.venv\Scripts\python.exe experiments\document_disjoint_robustness_138.py
.venv\Scripts\python.exe experiments\ablation_138_clean_005.py
.venv\Scripts\python.exe experiments\reconcile_legacy_vs_clean_lexical_138.py
```

The commands write new or canonical audit artifacts under `reports/`. They do
not upload data or require Kaggle network access. The Qwen3 command only
recomputes threshold selection from the downloaded pair-score artifact.

## Source of truth

Read `reports/CANONICAL_SCIENTIFIC_MANIFEST_138.md` before interpreting any
result. The manuscript is `draft/SW_BTED_FULL_DRAFT_CITED_V2.md`; the short
lecturer document is `reports/SW_BTED_PROJECT_REVIEW_BRIEF.md`.
